## 👋 About

I'm a **freelance Agentic AI developer**. Companies hire me to turn "we want an
AI agent" into a working, deployed service: LLM applications and multi-agent
systems built with **LangGraph**, taken from API to production.

Most agent demos break the moment real users, real money, or real data are
involved. I ship the layer above the demo:

- 🛡️ **Guardrails** against prompt injection and data leakage (OWASP LLM Top 10)
- 🧑‍⚖️ **Human-in-the-loop** approval gates that survive a restart
- 💰 **Cost-governed autonomy** — agents stay inside the budget you set
- 📊 **Evaluation scorecards** (faithfulness, cost, latency) gated in CI — measured, not vibes
- 🔍 **Observability** — tracing, structured logs and metrics to prove it works in production

**What you get:** a tested, typed, Dockerized system with a versioned quality
scorecard — not a notebook.
