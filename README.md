## 🧭 What I do

Most freelance scraping requests fall into one of three buckets — I build for all three, production-grade, every time:

- **"Extract this catalog/directory into a spreadsheet."** → fast, schema-validated scrapers with clean CSV/Excel exports.
- **"Watch this site and alert me when something changes."** → browser-driven monitors with change detection and real-time alerts (Slack/Discord/email).
- **"I need this data flowing into my systems, continuously."** → scheduled pipelines with a database and an authenticated REST API behind them.

On top of that, I build **guardrailed AI agent services** (LangGraph + FastAPI) for teams that want to add an LLM feature safely — with prompt-injection defenses, observability, and cost controls, not a chatbot demo glued together overnight.
